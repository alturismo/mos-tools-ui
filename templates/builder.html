Tool

IDs dürfen Buchstaben, Zahlen, _ und - enthalten. Die Tool-ID kann später nicht geändert werden.

Configuration variables

Choice options: eine Option pro Zeile als value|label. Default muss einem value entsprechen.

Shell scripts

Jedes Script ist ein unabhängiger Job. Muss mit #!/bin/sh oder #!/bin/bash beginnen. Ausführung erfolgt als Host-root.

Host dependencies

Command = ausführbarer Befehl, Package = Debian-Paket oder __system__.

Backup & Restore

Gesichertes Tool auswählen (auch gelöschte Tools). Ein Restore ersetzt den aktuellen Stand; zuvor wird automatisch eine Sicherung erstellt.

Delete tool

Löscht ausschließlich Builder-Tools. Vorher wird automatisch ein vollständiges Backup erstellt.
